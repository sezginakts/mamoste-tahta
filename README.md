# Okul Tahta

Okul uygulamasının akıllı tahta sayfası. Tahtanın tarayıcısında açılır, 6 haneli kod gösterir;
öğretmen telefondaki Okul uygulamasıyla bu kodla bağlanıp etkinlikleri tahtada açar ve yönetir.

Bu depo otomatik üretilir (`node tools/tahta/uret.mjs`, ana uygulama deposunda). Elle düzenleme.
