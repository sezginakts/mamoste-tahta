# Mamoste Tahta

Mamoste uygulamasının akıllı tahta sayfası. Tahtanın tarayıcısında açılır, 6 haneli kod gösterir;
öğretmen telefondaki Mamoste uygulamasıyla bu kodla bağlanıp etkinlikleri tahtada açar ve yönetir.

Bu depo otomatik üretilir (`node tools/tahta/uret.mjs`, ana Mamoste deposunda). Elle düzenleme.
